04 — Geodesy & Coordinates

座標系の考え方 WGS84 → ECEF → LOCAL ENU

原点は大通公園西4丁目（標高約22m + ジオイド高約33m = 楕円体高 55.2m）。WGS84_ELLIPSOID で ECEF から右手系ローカル座標（1単位 = 1m）へ変換します。

  • +X = 真東（East, m） / +Y = 鉛直上向き（Up, m）
  • +Z = 真南（South = -North, m：右手系 East × Up = South）
  • 大通グリッド回転：Y軸まわりに水平 +9.7°（反時計回り） 回転し、大通公園（東北東）と駅前通（南南東）に整列
  • 建物読み込み時に大通近傍の建物底面をサンプリングし、接地高度を自動キャリブレーション
ORIGIN = { lat: 43.06048, lon: 141.35145, height: 55.2 } ODORI_ROT_Y = 9.7 * Math.PI / 180

05 — City Streaming

PLATEAU 3D Tiles SSE & LRU STREAMING

国土交通省 Project PLATEAU（札幌市 01100）の全10区 tileset.json を 3d-tiles-renderer で並列ストリーミングします。

  • LOD2 優先 + 自動フォールバック：中央・北・東・西区はテクスチャ付き LOD2、他6区は LOD1 を自動組合せ
  • 動的エラー目標（SSE）：各区中心からのカメラ距離と移動速度に応じて errorTarget（7.5〜18+）を毎フレーム調整
  • 欠損防止 & メモリ制御：loadSiblings: true で区境の抜けを防ぎ、LRU キャッシュ（1800〜3200）でタイルを管理
  • ローカル Draco 展開：dist/draco/ の WASM デコーダで glTF ジオメトリを高速展開

06 — Scene Modules

何を重ねているか 6 INTEGRATED SUBSYSTEMS

Ground & DEM

2重リング地図 + 遠景山岳

国土地理院 2重リング（近景 z=16 / 遠景 z=13）を dem_png で頂点変位して道路地図・航空写真を描画。別レイヤで藻岩山・手稲山の遠景山岳を頂点カラーで配置。

Building Shader

GLSL カスタム建物表現

onBeforeCompile で接地AO・LOD2ガラス面の自動反射・LOD1の手続きファサード生成・季節連動の屋根積雪・夜間窓発光・ホワイト模型切替を実現。

Overlay

雪まつり演出（冬連動）

大通4・5・7丁目の大雪像3基（城のライブプロジェクションマッピング）、実寸147m TV塔の電光時計、すすきの氷像・ネオン、車両・市電を実寸配置。

Transit

地下鉄全3線 + JR 3D 運行

南北・東西・東豊線（49駅）と JR3路線を CatmullRomCurve3 高架/地下軌道と InstancedMesh 46編成で駅停車付き運行。地下透視モード対応。

Atmosphere

空シェーダ & 季節降水

半径36km スカイドームの GLSL（雲量 uCloudCover・曇天度 uOvercast・星・太陽散乱）と、雪・雨スジ・桜吹雪・落葉パーティクルを制御。

Cinema UI

カメラ・季節・録画 UI

7ショット自動演出、画面内カメラパッド、札幌全10区・Geolocation 現在地ジャンプ、春夏秋冬×4天候×4時間帯切替、WebM 録画を搭載。

07 — Rail & Underground X-Ray

地下鉄全3路線 & JR の 3D 可視化 MULTI-LEVEL TRANSIT

札幌市の地下・地上・高架にまたがる鉄道網を実 WGS84 駅座標と国土地理院 DEM 標高に沿って再現し、全46編成をリアルタイム運行します。

南北線 16駅（5000形・高架シェルター付） 東西線 19駅（8000形） 東豊線 14駅（9000形） JR函館・千歳・学園都市線
  • 2段階の地下透視：通常時は THREE.GreaterDepth パスで地面・建物に遮蔽された地下列車のみ透過発光。地下透視モードでは地面自体を半透明化（ガラス床カットアウェイ）
  • 低負荷 60 FPS 描画：全46編成（約250両）の車体・ライン帯・発光窓・前後ライトを少数の InstancedMesh で一括更新し、カーブに追従
  • リアルな加減速＆駅停車：駅間距離から所要時間と停車（dwell）を計算し、複線左側通行ですれ違い運行

08 — Rendering

描画・ライティングパイプライン EFFECT COMPOSER

3D Scene→ RenderPass→ UnrealBloomPass→ OutputPass (ACES + sRGB)→ WebGL Canvas
  • ACES Filmic トーンマップ：高輝度のネオン・雪像ライト・列車ヘッドライトが白飛びせず映画的な階調に収束
  • PMREM 環境マップ：RoomEnvironment により氷像・創成川・ビルガラス・雨天の濡れた路面に自然な反射を付与
  • PCF Soft Shadow + 16m スナップ：太陽シャドウカメラを注視点へ16m刻みで追従させ、全10区移動時も影のチラつき（texel swimming）を防止
  • 指数フォグ（FogExp2）：時間帯と天候（快晴/曇り/雨/雪）で密度と色を連動制御

09 — Tooling & Delivery

ビルドと静的配信 ESBUILD PIPELINE

src/**/*.js→ esbuild (es2022)→ IIFE minified
template*.html→ <!--__BUNDLE__-->→ dist/*.html
  • Three.js や 3d-tiles-renderer を含む依存を 1 本の IIFE にバンドル・minify して HTML へインライン展開
  • node_modules/three/.../draco/gltf から Draco WASM 3ファイルを dist/draco/ へ自動コピー
  • serve.mjs が dist/ をローカル HTTP（既定 127.0.0.1:4173）で配信
  • 出力は静的ファイル群のみのため、任意の静的ホスティングへそのまま配置可能

10 — Takeaways

要点まとめ KEY ARCHITECTURE POINTS

  • 2つの体験入口：近景演出の Stylized 版（index.html）と実寸都市の PLATEAU 版（plateau.html）
  • 測地基準の統一：大通西4丁目原点の 1m 右手系座標（+9.7° 街区軸）に全レイヤを精密整列
  • 全市ストリーミング：3D Tiles（SSE + LRU）と国土地理院2重リング地図/DEMで札幌全10区を快適に描画
  • 都市インフラの可視化：地下鉄全3路線＋JR3路線の46編成運行と GreaterDepth／ガラス床による地下透視
  • 軽量な静的構成：esbuild で HTML 中心の静的アセットに集約し、サーバーレスで完結
